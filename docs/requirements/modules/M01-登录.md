# 登录

用户选择身份、输入学工号，完成模拟人脸比对后，点击登录进入 `home`。不提供注册和密码登录。

## 身份选择

- 提供“学生”“导师”“负责人”三个选项，单选，登录前必须选择一个。
- 身份以用户选择为准，不根据学工号推断，不查询账号是否存在或是否与所选身份匹配。
- 登录后记录所选身份，用于展示对应角色的首页内容和功能入口。

## 学工号规则

- 共 10 位数字：四位年份 + 三位代码 + 三位序号，例如 `2026001001`、`2026012001`。
- 中间三位代码不固定为 `017`，允许任意三位数字，不校验具体专业代码是否存在。
- 格式校验表达式：`^[0-9]{10}$`。
- 只检查格式，不查询账号是否存在，不要求预置账号名单。
- 三位序号在人与人之间递增属于编号规则，登录时不校验序号是否连续。
- 学工号为空或不符合格式时，统一提示“学工号异常”。
- 人脸比对成功后锁定学工号，不允许修改；登录后也不提供修改学工号的功能。

## 操作流程

1. 初始状态下，登录按钮禁用。
2. 用户选择身份，输入学工号，点击“人脸比对”按钮。格式不正确时提示“学工号异常”，登录按钮保持禁用。
3. 格式正确时，点击按钮即视为比对成功，显示“比对成功”，锁定学工号输入框。身份已选择且比对成功后，登录按钮亮起并启用；未选择身份时保持禁用。
4. 用户点击“登录”，进入 `home`，展示所选身份对应的内容；比对成功后不自动跳转。

人脸比对仅为模拟操作，不调用摄像头，不采集、上传或存储人脸数据。

## 验收要点

- `2026001001`、`2026002001`、`2026012001`、`2026013001`、`2026017001` 均符合格式，无论是否存在对应账号，选择身份后都可完成模拟比对并点击登录进入 `home`。
- 空值、长度不是 10 位或包含非数字时，提示“学工号异常”；不能因中间三位不是 `017` 而拒绝登录。
- 未完成比对时不能点击登录；比对成功后学工号输入框不可编辑，登录后也不能修改学工号。

- 未选择身份时不能登录；三个身份均可单独选择，登录后展示对应角色的内容和功能入口。
