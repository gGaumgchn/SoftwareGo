# 主页面

用户登录后进入 `home`，查看当前选拔阶段、公告及个人待办，并通过左侧菜单进入对应功能。

## 页面布局

- 左上角展示项目标识“实训室选拔系统”。
- 右上角展示用户姓名，下方以小字展示“学生／导师／负责人”；当前没有姓名时显示学工号，不额外要求填写姓名。
- 左侧为功能菜单，右侧为系统展示区；展示区上半部分展示阶段和相关公告，下半部分展示个人待办摘要。

## 左侧菜单

- 学生依次展示：主页面、公告、查看实训室信息、志愿填报、拟录取确认、个人待办。
- 导师展示：主页面、公告、实训室信息、申请与录取管理、个人待办。
- 负责人展示：主页面、公告、阶段管理、个人待办。
- “公告”为只读列表入口，公告发布后不可修改或删除，不提供公告管理功能。
- 第二、第三轮录取的填报阶段，学生点击“志愿填报”进入分轮补录；补录页顶部只读展示有剩余名额的导师，仍使用三个导师姓名输入框填报，不增加搜索或候选选择。
- 菜单按登录时选择的身份展示，点击后进入对应页面；当前菜单项高亮。

## 阶段与公告展示

- 展示全体用户统一的选拔进度，顺序为：集中宣讲 → 实训室开放日 → 三轮录取 → 调剂阶段 → 正式入组。
- 每轮录取包含“志愿填报 → 面试 → 拟录取确认”，共循环三次；展示时带上轮次，例如“第二轮 · 志愿填报”。
- 上半部分展示当前阶段、起止时间、截止倒计时及相关公告；不在此页面实现线下宣讲、走访或面试。
- 各阶段时间由负责人配置，特殊情况下可调整；调整后阶段、时间和倒计时同步更新，以服务端时间为准。
- 公告摘要可点击进入对应公告详情。

## 个人待办展示

- 下半部分只展示与当前用户相关且当前可办理的事项，例如学生的“填报志愿”“确认拟录取”，并展示适用的截止时间。
- 点击待办内容进入个人待办页面；没有待办时显示“暂无待办”。
- 待办随用户状态和阶段更新，已完成或已截止的事项不继续作为可办理待办展示。
- 系统阶段与个人状态分别展示：学生已经录取，主页面仍显示全体统一的当前阶段。

## 已录取学生

- 在主页面用户状态区域明显标记“已录取”，并展示最终录取的实训室、导师及录取状态；三轮中主动确认的录取及三轮结束后的统筹调剂结果均在此展示。
- 保留“志愿填报”菜单，点击时提示“已被录取！”，不进入填报或补录页面。
- 不再生成志愿填报、分轮补录或拟录取确认待办；学生仍可查看阶段、公告及最终录取结果。

## 异常处理与验收要点

- 暂无阶段配置时显示“阶段暂未配置”，不虚构当前阶段和倒计时；暂无相关公告时显示“暂无公告”。
- 阶段或待办加载失败时显示“加载失败，请重试”，不将加载失败当作“暂无待办”。
- 学生、导师、负责人登录后，身份标签和菜单与所选身份一致；没有姓名时正确显示学工号。
- 学生菜单显示“拟录取确认”，负责人菜单不再显示“公告管理”；“公告”菜单只读，不能新增、修改或删除公告。
- 三轮阶段名称明确带有轮次，负责人调整时间后页面显示与实际阶段一致。
- 第二、第三轮点击“志愿填报”可进入补录，补录页展示剩余名额导师只读列表，不出现搜索框或可点击候选。
- 已录取学生能看到“已录取”标记及最终实训室、导师和调剂结果，点击“志愿填报”只提示“已被录取！”，不能进入填报或补录。
- 个人待办点击进入个人待办页面；无待办时展示空状态，不影响阶段和公告浏览。

阶段及学生录取路径见 [学生旅途](../学生旅途.md)。
