# 志愿填报

学生填写意向导师姓名、调剂意愿并上传个人简历，提交本人的志愿申请。

## 填写规则

- 提供三个普通的导师姓名输入框，均标注“可选”，不使用搜索框或搜索候选列表。
- 至少填写一名导师，最多填写三名；三个志愿平行，不区分优先级。
- 仅输入空格视为未填写；同一导师姓名不能重复填写。
- 上传一份 PDF 格式的个人简历，提交前可替换。文件大小上限暂不规定。
- 分别填写“是否同意实训室内调剂”和“是否同意学院内调剂”，每项均选择“同意”或“不同意”；选择不同意不影响正常志愿提交。
- 两项调剂意愿供三轮结束后仍未录取时使用，采用最后一次成功提交的记录。
- 统筹调剂结合面试分数及剩余名额，优先级为“实训室内调剂 > 学院内调剂”。实训室内由志愿导师所在实训室讨论是否接收；未接收且同意学院内调剂的，自动进入跨实训室调剂。不同意实训室内调剂但同意学院内调剂的，直接进入学院内调剂。
- 调剂接收后直接形成录取结果，不再询问学生，也不要求学生再次确认。详见 [学生旅途](../学生旅途.md)。

## 提交流程

1. 初始状态下，提交按钮禁用。
2. 至少填写一个导师姓名且不重复、两项调剂意愿均已选择，并且 PDF 简历上传成功后，提交按钮亮起并启用；其余导师输入框可以留空。
3. 未填写任何导师姓名、未完成调剂意愿选择、没有简历、上传尚未完成或上传失败时，提交按钮保持禁用。
4. 点击提交后，保存填写的导师姓名、两项调剂意愿与简历，并显示“提交成功”；提交过程中禁用按钮，避免重复提交。

## 异常提示

- 上传非 PDF 文件：提示“请上传 PDF 格式的简历”，不计为有效简历。
- 导师姓名重复：提示“导师姓名不能重复”，提交按钮禁用。
- 上传失败：提示“简历上传失败，请重试”。
- 提交失败：提示“提交失败，请重试”，保留当前填写内容及已上传的简历。

## 验收要点

- 三个导师姓名输入框均显示“可选”；仅填写一个、完成两项调剂意愿选择并上传 PDF 后即可提交。
- 三个框均为空或仅含空格，或者没有成功上传 PDF，均不能提交。
- 不出现导师搜索或候选列表；不要求三个输入框全部填写。
- 两项调剂意愿分别保存；均选择“不同意”也可提交，不得在未同意的范围内安排调剂。
- 三轮结束后按最后一次成功提交的意愿调剂；两项均同意时先处理实训室内接收，未接收再进入学院内调剂；最终接收不要求学生确认。
- 提交成功后，保存的志愿、调剂意愿和简历与本次提交内容一致。
