# 发送录取意愿

导师查看本轮申请和简历，在线下面试结束后录入分数，设置录取分数线，由系统按顺序发放拟录取。本功能用于三轮志愿录取，不用于三轮结束后的统筹调剂。

## 核心规则

- 仅导师可使用，只能查看和处理申请到本人名下的本轮学生及其简历。
- 导师录入面试分数，系统按分数从高到低排序；未评分学生不参与发放。
- 导师设置录取分数线，分数大于或等于分数线的学生才有资格收到拟录取；达标人数不足时允许名额空缺，不向线下学生发放。
- 同分学生由导师手动确定先后顺序，不随机排序；涉及发放顺序的同分未处理前，不向这些学生发放。
- 使用导师本轮招生名额，“已确认人数 + 待确认人数”达到名额时暂停发放，即使还有达标学生也不超发。
- 学生放弃、超时或确认其他导师后，释放本导师对应的待确认名额，在本轮允许发放的时间内继续向下一位达标学生发放。
- 已有最终录取去向的学生不再接收拟录取；同一导师同一轮不向同一学生重复发放。
- 达到本轮发放或确认截止时间后，不再递补发放，不自动延长确认期限。
- “发放”指在系统内生成拟录取记录，供学生登录查看，不做短信、邮件或消息推送。学生确认规则见 [拟录取确认](M05-拟录取确认.md)。

## 操作流程

1. 导师查看本轮申请列表及学生简历，在线下面试后录入分数。
2. 查看分数排序，处理同分顺序，设置录取分数线，并查看本轮名额。
3. 点击“发放拟录取”，系统按排序依次向达标且尚未录取的学生发放，直至名额占满或无可发放的达标学生。
4. 导师查看待确认、已确认及已放弃状态；有效时间内出现空缺时，系统按相同规则顺位递补。

## 异常处理

- 非导师或请求他人申请资料：拒绝访问。
- 分数或分数线为空、不是有效数值：提示“请填写有效分数”，不保存该项输入。
- 同分顺序未确定：提示“请先确定同分学生顺序”，暂停相关发放。
- 无剩余名额：提示“名额已满”，暂停发放；释放名额且未截止时可继续递补。
- 没有可发放的达标学生：提示“暂无可发放的达标学生”，不降低分数线或超额发放。
- 已截止：提示“本轮拟录取发放已截止”，拒绝发放或递补。
- 重复点击或重复执行发放：不生成重复意向，不重复占用名额。

## 验收要点

- 导师只能看到本人本轮申请及简历，能录入分数并查看降序排名。
- 等于分数线可发放，低于分数线或未评分不可发放；同分按导师确定的顺序处理。
- 名额先占满时立即暂停，不必继续发放到最低分数线；达标人数不足时保留空缺。
- 待确认意向占用名额；学生放弃、超时或确认其他导师后，未截止时按顺序递补。
- 并发、重复操作不能造成超发或重复发放；截止后不再递补。
