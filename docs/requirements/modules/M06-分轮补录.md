# 分轮补录

在第二、第三轮录取的填报阶段，为尚未确认录取的学生开放再次填报志愿的入口。

## 核心规则

- 第一、第二、第三轮均经历“志愿填报 → 面试 → 拟录取确认”，面试在线下进行；三轮结束后不再安排新一轮填报，未录取学生进入统筹调剂，详见 [学生旅途](../学生旅途.md)。
- 检查学生是否已有确认接受的录取；已有录取结果的，不开放补录填报。三轮后的调剂录取同样属于已录取，不要求学生确认。
- 没有已确认录取且当前轮次处于填报开放时间内，才允许再次填报；仅收到拟录取但尚未确认，不视为已录取。
- 每轮仅展示仍有剩余名额的导师，填报对象须为本轮仍有名额的导师。
- 填报沿用 [志愿填报](M04-志愿填报.md) 的导师姓名、PDF 简历及两项调剂意愿规则，不增加搜索框。
- 各轮申请单独保存，不覆盖上一轮志愿及处理结果。
- 补录拟录取沿用 [拟录取确认](M05-拟录取确认.md) 的规则，必须主动确认，超时自动放弃；录取后不再开放后续轮次填报。

## 操作流程

1. 学生进入补录页面，系统检查当前轮次、开放时间及学生录取状态。
2. 符合条件时，展示有剩余名额的导师并开放志愿填报；不符合条件时显示原因。
3. 学生填写并提交；系统在提交时再次检查录取状态、填报时间及所填导师是否仍有名额。
4. 提交成功后，保存为本轮申请并显示“提交成功”，后续按拟录取及确认流程处理。

## 异常处理

- 已确认录取：不开放填报；即使学生使用旧页面提交，也拒绝并提示“你已确认录取，无需参加补录”。
- 补录尚未开放或已经截止：禁止填报，分别提示“补录填报尚未开始”或“补录填报已截止”。
- 本轮无剩余名额：显示“本轮暂无可填报名额”，不开放填报。
- 提交时所填导师已无名额：提示“所填导师已无剩余名额，请重新选择”，保留填报内容供修改。

## 验收要点

- 未录取学生在补录开放期间可以再次填报，已确认录取学生不能填报。
- 收到拟录取但未确认的学生，不因收到意向而被判定为已录取。
- 学生打开页面后才确认录取，继续提交时也会被拒绝。
- 补录未开始、已截止或没有剩余名额时，不能提交申请。
- 新一轮填报不覆盖历史记录；补录拟录取仍须主动确认，确认后不能参加后续补录。
