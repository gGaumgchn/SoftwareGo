# 阶段管理

负责人配置选拔各阶段的起止时间，保存后立即生效，并可选择是否就本次调整发布公告。阶段时间用于主页面当前阶段、倒计时及志愿填报、拟录取确认等开放与截止判断。

## 核心规则

- 仅负责人可使用；学生、导师不能进入，直接访问地址也拒绝。
- 阶段名称和顺序固定，不可新增、删除或重命名。共 5 个顶层阶段：集中宣讲、实训室开放日、三轮录取、调剂、正式入组。
- “三轮录取”展开为第一轮录取、第二轮录取、第三轮录取分别配置起止时间；每轮内的志愿填报、面试、拟录取确认共用该轮时间，不单独配置子阶段时间。
- 所有阶段起止时间必填，精确到分钟；开始时间必须早于结束时间；按流程顺序，前一阶段结束不得晚于后一阶段开始，允许阶段之间留有间隔。
- 允许填写已经过去的时间，用于补录或临时调整。
- 保存成功后立即生效，即使不发布公告：主页面当前阶段、倒计时及志愿填报、补录、拟录取确认的时间判断均按新配置执行，以服务端时间为准。
- 当前时间落在某阶段区间内时，该阶段为当前阶段；落在两个阶段之间时，显示下一个阶段及开始时间；全部阶段结束后显示“选拔已结束”。
- 再次修改时更新原有配置，不新增重复阶段记录，不保留阶段配置的历史版本。
- 公告为可选项。选择发布时，系统按本次变更自动生成公告标题和正文，发布前可编辑；不发布时只更新阶段，不产生公告记录。
- 首次配置时公告列出全部阶段；后续修改时只列出本次变更的阶段，并同时展示原时间与新时间。
- 公告面向全体用户，发布后进入公告列表并在主页面展示。每次保存最多生成一条公告。
- 阶段时间调整不改变已经形成的学生状态：不恢复已自动放弃的拟录取，不重新开放已按原时间截止的填报或确认，也不回滚已提交的志愿和录取结果。
- 尚未配置任何阶段时，主页面按 [主页面](../M03-主页面.md) 显示“阶段暂未配置”，阶段管理页展示空白表单。

## 操作流程

1. 负责人进入阶段管理；没有配置时展示空白表单，已有配置时展示各阶段当前的起止时间。
2. 填写或修改各阶段起止时间，并选择是否发布公告。
3. 选择发布公告时，展示自动生成的公告标题和正文，可编辑；不选择时不展示公告内容。
4. 点击保存，系统校验时间是否完整、起止是否正确及阶段顺序；校验通过后保存并立即生效。
5. 选择发布公告的，保存成功后继续发布公告；全部成功提示“保存成功，公告已发布”，未选择发布提示“保存成功”。
6. 保存或发布过程中禁用按钮，避免重复提交。

## 异常处理

- 非负责人访问：拒绝进入，提示“仅负责人可配置阶段”。
- 任一阶段时间未填写：不能保存，提示“请填写完整的阶段时间”。
- 开始时间不早于结束时间：提示“阶段结束时间必须晚于开始时间”，不保存。
- 阶段顺序颠倒或时间重叠：提示“阶段时间必须按流程顺序设置且不能重叠”，标出冲突阶段，不保存。
- 选择发布公告但标题或正文为空：提示“公告内容不能为空”，不保存阶段，也不发布公告。
- 阶段保存成功但公告发布失败：阶段变更仍生效，提示“阶段已保存，公告发布失败，请重试”；重试只发布公告，不重复保存阶段，也不生成重复公告。
- 重复点击保存：只执行一次保存，最多生成一条公告。
- 页面加载失败：提示“加载失败，请重试”，不将加载失败展示为空白配置或“阶段暂未配置”。

## 验收要点

- 仅负责人能进入阶段管理；学生、导师直接访问被拒绝。
- 可配置 5 个顶层阶段的时间，三轮录取按第一、第二、第三轮分别保存起止时间；阶段名称和顺序不可修改。
- 保存后即使不发布公告，学生和导师刷新页面也能看到新的阶段、时间和倒计时。
- 修改后保存更新原配置，不产生重复阶段记录；此前发布的公告不受影响。
- 时间未填完整、开始晚于结束、顺序颠倒或重叠时不能保存，并显示对应提示。
- 选择发布公告时，自动生成的公告内容可编辑；发布后全体用户可见，主页面同步展示。
- 不选择发布公告时，阶段立即生效，公告列表不新增记录。
- 重复点击保存只产生一次保存和一条公告；公告发布失败不影响已保存的阶段，可单独重试。
- 阶段调整不恢复已放弃的拟录取、不重新开放已截止的填报，也不改变已提交的志愿和录取结果。
- 首次进入无配置时展示空白表单；加载失败时提示重试，而不是显示为空配置。
