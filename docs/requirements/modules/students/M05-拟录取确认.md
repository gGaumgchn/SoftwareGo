# 拟录取确认

学生在每轮确认截止时间前，从收到的志愿拟录取中选择一个并主动确认，确定录取去向。本功能适用于第一、第二、第三轮录取；三轮结束后的统筹调剂直接形成录取结果，不需要学生确认。

## 核心规则

- 展示本人本轮收到的志愿拟录取，包括导师、所属实训室、轮次、确认截止时间及当前状态。
- 统筹调剂可能安排非志愿导师，结果直接展示，不提供确认按钮，也不执行本功能中的超时放弃规则。调剂依据及顺序见 [学生旅途](../../学生旅途.md)。
- 只能确认一个拟录取。即使只收到一个，也必须主动点击确认，不自动确认。
- 确认成功后不可更改，其余拟录取自动标记为“已放弃”。
- 到达确认截止时间仍未确认的拟录取，自动标记为“已放弃”；已确认的结果保持不变。
- 截止判断以系统服务端时间为准，在截止时间之前才能确认，到达截止时间即不可确认。

## 操作流程

1. 学生查看拟录取列表；待确认且未截止的拟录取显示可用的确认按钮。
2. 点击确认按钮，弹出提示：“确认后不可更改，其他拟录取将自动放弃”。
3. 取消提示框，不改变任何状态；继续确认后提交选择，提交期间禁用按钮，避免重复操作。
4. 确认成功后，所选拟录取标记为“已确认”，其他拟录取标记为“已放弃”，所有确认按钮不可用。
5. 无需学生打开页面，系统也应在截止时自动处理尚未确认的拟录取。

## 异常处理

- 未收到拟录取：显示“暂无拟录取”，不提供确认操作。
- 页面未刷新但实际已经截止：拒绝确认，提示“确认时间已截止”，更新页面状态。
- 已确认一个后再次确认其他意向：拒绝操作，提示“已确认录取，不可更改”；并发或重复请求也不能产生多个确认结果。
- 提交失败：提示“确认失败，请刷新查看结果后重试”，不在页面直接显示确认成功，以系统保存的结果为准。

## 验收要点

- 只有一个拟录取时，必须主动确认；超时未确认自动放弃。
- 存在多个拟录取时，确认一个后，其余自动放弃；取消二次提示不改变状态。
- 截止前未确认的拟录取，到达截止时间后不可确认，并自动变为“已放弃”。
- 即使使用旧页面或同时提交多个确认请求，也只能形成一个确认结果。
- 已确认的结果不会因截止处理被改为“已放弃”。
- 三轮后的调剂录取不展示待确认操作，不因学生未点击确认而被标记为放弃。
