# 提交实训室信息

导师自行填写实训室和个人招生信息，提交后供学生查看，支持后续修改。

## 填写内容

以下内容均为必填：

- 实训室名称。
- 实训室位置，如校区、楼栋及房间号。
- 该导师计划招收人数，须为正整数。
- 导师姓名、研究方向及联系方式。
- 导师简历，上传 PDF 文件。

## 核心规则

- 仅导师可使用，且只能提交和修改本人负责的信息。
- 实训室名称和位置由导师自行填写，不要求负责人预先配置或从列表中选择。
- 招生人数按导师本人计算，同一实训室的总计划人数由所属导师的计划人数汇总，不重复填写。
- 提交后再次修改时更新本人原有信息，不新增重复记录；不修改其他导师提交的信息。
- 修改招生人数时，不得小于本人已确认录取与待确认拟录取合计占用的名额。

## 操作流程

1. 导师进入填写页面；已有信息时展示已保存内容。
2. 填写各项信息并上传 PDF 简历；全部必填项有效且上传成功后，提交按钮亮起并启用。
3. 点击提交，保存信息并提示“提交成功”；提交过程中禁用按钮，避免重复操作。
4. 提交成功后学生可查看；导师后续可重新进入页面修改并提交。

## 异常处理

- 必填项为空或仅含空格、简历未上传成功、人数不是正整数：提交按钮禁用。
- 上传非 PDF 文件：提示“请上传 PDF 格式的简历”。
- 简历上传失败：提示“简历上传失败，请重试”。
- 修改后的名额小于当前占用人数：拒绝保存，提示“计划招收人数不能小于当前已占用名额”。
- 提交失败：提示“提交失败，请重试”，保留当前填写内容；原已保存的信息不变。
- 非导师或请求修改其他导师信息：拒绝操作。

## 验收要点

- 导师无需负责人预先建立实训室，即可填写名称、位置及个人招生信息。
- 缺少任一必填项、简历未上传成功，或人数为零、负数、小数、非数字时，不能提交。
- 提交成功后学生能查看对应信息；导师修改后更新原记录，其他导师的信息保持不变。
- 实训室总计划人数等于所属导师计划人数之和，调整名额不突破已有占用约束。
