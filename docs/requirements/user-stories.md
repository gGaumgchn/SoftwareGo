# SoftwareGo 用户故事

依据 `docs/requirements` 下的需求文档整理，角色分为学生、导师、负责人。核心功能包括：登录、主页面、志愿填报、拟录取确认、实训室信息填写、发放拟录取、阶段管理、分轮补录。

说明：

- 公告管理已废除，公告仅可查看；查看公告并入各角色“主页面”故事。
- “发送录取通知”在需求文档中对应导师的“发放拟录取／发送录取意愿”，本文统一使用“发放拟录取”。
- 统筹调剂线下进行，线上仅展示结果，不提供学生确认操作。

## 学生

| 编号 | 用户故事 |
| --- | --- |
| US-S01 | 作为学生，我想要选择“学生”身份、输入 10 位学工号并完成模拟人脸比对后登录，以便无需注册或密码即可进入学生首页。 |
| US-S02 | 作为学生，我想要在主页面查看当前选拔阶段、起止时间、倒计时、相关公告及我的个人待办，以便清楚现在该做什么、何时截止。 |
| US-S03 | 作为学生，我想要填写一至三名意向导师、上传 PDF 简历并分别选择两项调剂意愿后提交，以便申请心仪的实训室。 |
| US-S04 | 作为学生，我想要查看本轮收到的拟录取、确认截止时间及状态，并在截止前主动确认一个，以便确定录取去向。 |
| US-S05 | 作为学生，我想要在第二、第三轮查看仍有剩余名额的导师并重新填报志愿，以便在尚未录取时继续争取录取机会。 |
| US-S06 | 作为学生，我想要查看最终录取的实训室、导师及“已录取”状态（包括三轮后的统筹调剂结果），以便确认自己的最终去向。 |
