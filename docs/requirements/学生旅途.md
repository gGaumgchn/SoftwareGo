# 学生旅途

流程依据：[选拔背景图](../../background.jpg)。具体日期由负责人配置，不使用图片中的固定日期。

## 整体流程

实训室宣讲 → 实训室开放 → 第一轮录取 → 第二轮录取 → 第三轮录取 → 未录取学生统筹调剂 → 查看最终结果。

每轮录取均包含：**志愿填报 → 面试 → 拟录取确认**。

## 学生经历

| 阶段 | 学生操作与系统表现 |
| --- | --- |
| 实训室宣讲 | 面向全体学生，系统展示阶段和公告；宣讲在线下进行 |
| 实训室开放 | 面向全体学生，系统展示阶段和公告；走访在线下进行 |
| 第一轮录取 | 填报志愿、PDF 简历及两项调剂意愿，参加线下面试，再主动确认一个拟录取；超时未确认视为放弃 |
| 第二轮录取 | 仅尚未录取的学生参加，按剩余名额重新填报，再经历面试、拟录取确认 |
| 第三轮录取 | 仅尚未录取的学生参加，再次经历填报、面试、拟录取确认；不再安排第四轮填报 |
| 统筹调剂 | 第三轮结束后，仅处理仍未录取的学生；依据最后一次成功提交的调剂意愿安排，不再要求学生确认 |
| 最终结果 | 学生查看最终录取实训室、导师及结果状态；实际入组在线下进行 |

任意一轮确认录取后，不再参加后续轮次或统筹调剂，等待最终结果。历轮填报记录分别保留。

## 统筹调剂规则

- 采用学生最后一次成功提交的“是否同意实训室内调剂”和“是否同意学院内调剂”，不是强制要求使用第三轮数据；若第三轮未填报，采用此前最后一次成功提交的记录。
- 优先级为 **实训室内调剂 > 学院内调剂**，结合剩余名额和面试分数安排。
- 同意实训室内调剂的，由最后一次志愿中导师所在实训室内部讨论是否接收；接收后直接形成调剂录取结果，无需学生再次确认。
- 实训室内未接收且同意学院内调剂的，自动进入学院内调剂；若不同意实训室内调剂但同意学院内调剂，则直接进入学院内调剂。
- 学院内调剂是跨实训室调剂，安排接收后直接形成录取结果，无需学生再次确认。
- 不同意相应范围调剂的，不安排该范围的调剂；没有可用调剂意愿、没有填报记录或最终未获接收的，保持未录取状态，交由负责人线下处理。
- 每名学生最终只能有一个录取去向，且不能突破招生名额。

## 与模块需求的关系

- [志愿填报](modules/students/M04-志愿填报.md)：每轮记录志愿、简历及调剂意愿。
- [拟录取确认](modules/students/M05-拟录取确认.md)：仅适用于三轮内的志愿拟录取，学生必须主动确认。
- [分轮补录](modules/students/M06-分轮补录.md)：第二、第三轮仅对未录取学生开放；三轮后的统筹调剂不再使用学生确认流程。
