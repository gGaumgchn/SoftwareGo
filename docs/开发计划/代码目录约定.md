### 2.1 每个业务模块的固定分层

```text
com.softwarego.selection.<module>/
├── controller/       # 只收参、@Valid、调 Service、返回 Result
├── service/          # 业务规则、事务、数据归属、状态机
├── mapper/           # Mapper 接口，只写 SQL 声明
├── domain/           # 数据库实体，字段与表列对应
└── dto/              # 请求/响应对象，Controller 不返回实体
```

### 2.2 以 `stage` 模块为例

| 类型 | 路径 |
| --- | --- |
| Controller | `stage/controller/StageController.java`、`stage/controller/ManagerStageController.java` |
| Service | `stage/service/StageService.java`、`stage/service/StageConfigService.java` |
| Mapper 接口 | `stage/mapper/StageMapper.java` |
| 实体 | `stage/domain/Stage.java` |
| 请求/响应 DTO | `stage/dto/CurrentStageResponse.java`、`stage/dto/StageSaveRequest.java` |
| Mapper XML | `src/main/resources/mapper/stage/StageMapper.xml` |
| 测试 | `src/test/java/com/softwarego/selection/stage/StageServiceTest.java` |

规则：

- 业务代码只放对应模块目录；`common/`、`config/` 只放通用基础设施。
- SQL 只写在 Mapper XML（或简单查询的 Mapper 注解），Service 不拼 SQL。
- 跨模块读取通过 Service 调用，不直接注入其他模块的 Mapper。
- 请求 DTO 和响应 DTO 分开命名；Controller 不直接返回 `domain`。
- 新增模块时，按 `controller/service/mapper/domain/dto` 建齐，并在 `resources/mapper/<module>/`、`src/test/java/.../<module>/` 建对应目录。

### 3.1 前端落位规则

- 每个后端模块对应一个 `src/api/<module>.js`，页面不直接写 Axios。
- 公共组件放 `src/components/`；只有单个页面使用的子组件放该页面同目录的 `components/` 下。
- 跨页面状态才放 `src/stores/`；页面内状态用组件 `ref/reactive`，不滥用 Pinia。
- 路由、角色守卫统一在 `src/router/index.js`，不在页面里手写跳转权限。
- 主题变量只在 `variables.css` 定义；页面不散落新的硬编码色值。
- 工具函数放 `src/utils/`，模板中不写复杂表达式。
- 页面文件命名 `XxxView.vue`；公共组件命名 `Xxx.vue`；composable 命名 `useXxx.js`。

### 3.2 以 `stage` 模块为例

| 类型 | 路径 |
| --- | --- |
| API 封装 | `src/api/stage.js` |
| 负责人页面 | `src/views/manager/StageView.vue` |

## 5. 命名与放置规则

- 后端类：`PascalCase`；方法/变量：`camelCase`；常量：`UPPER_SNAKE_CASE`。
- Mapper XML：`<Entity>Mapper.xml`，namespace 与 Mapper 接口全限定名一致。
- 前端组件：`PascalCase.vue`；API 函数：`getXxx / createXxx / updateXxx / confirmXxx`。
- 数据库：表名列名 `snake_case`；SQL 关键字大写。
- 新增页面先放对应角色目录：
  - 学生：`views/student/`
  - 导师：`views/teacher/`
  - 负责人：`views/manager/`
  - 全体公共：`views/` 根目录
- 新增公共组件先判断是否跨两个以上页面使用；只有一处使用不放进 `components/`。
